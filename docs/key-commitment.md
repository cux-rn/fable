# Fable-AEAD 的密钥承诺（key commitment）归约

版本：v0.3 分析（2026-09-14）。对应规范 §3.5 与 §0 的声明："密钥承诺 128 bit（256 bit 标签），128 bit 标签时降为 64 bit"。

## 1. 声明的精确含义

采用 Bellare–Hoang（EUROCRYPT 2022）的记号：

- **CMT-1**（密钥承诺）：攻击者输出 (K, N, A, M) 与 (K', N', A', M')，K ≠ K'，使得两者加密得到**相同的** (C, T)。等价地：同一 (C, T) 能被两个不同密钥成功解密。
- **CMT-4**（全承诺）：同上但只要求 (K, N, A, M) ≠ (K', N', A', M')。CMT-4 ⇒ CMT-1。

Fable 的标签在 §3.5 定义为 T = S[0..7]，其中 S = P_12(X)，X 是最终化前的完整 512 bit 状态。**下面证明 Fable-AEAD 满足 CMT-4（因此也满足 CMT-1），强度为 τ/2 bit，τ 为标签比特数**；在理想置换模型下这是紧的。

## 2. 记号与最终化前状态

对一次加密 (K, N, A, M)，记：

- 初始化：S_0 = P_12(IV0 ‖ IV1 ‖ K ‖ N)，然后 S_0[8..15] ⊕= K。
- 吸收 A（每块 P_ℓ，ℓ = 8 或 6）、域分离 S[15] ⊕= 0x80000000、吸收/挤出 M 的各块。记最后一个（填充过的）消息块异或进速率后的状态为 Y = (Y_R, Y_C)，Y_R ∈ {0,1}^256 为速率、Y_C ∈ {0,1}^256 为容量。
- 最终化：X = (Y_R, Y_C ⊕ K)，S = P_12(X)，T = trunc_τ(S[0..7])。

关键事实（由构造直接得到）：

1. **X 是 (K, N, A, M) 的确定性函数**，且 C 的每一块都是沿途状态速率部分的函数。
2. **给定 (C, T) 和 (K', N', A')，M' 由解密唯一确定**（M' = C ⊕ 密钥流），因此 CMT-1 攻击者"选择 K' 使 (C,T) 解密成功"与"选择 (K', N', A', M') 使加密得到同一 (C, T)"是同一件事。

## 3. 归约

**引理 1（状态不同则归约为截断输出碰撞）。** 设两组输入产生相同的 (C, T)，其最终化前状态为 X ≠ X'。则 P_12(X) 与 P_12(X') 在前 τ 比特上相同，即攻击者找到了函数 F(x) := trunc_τ(P_12(x)) 的一个碰撞。

证明：T = trunc_τ(P_12(X)) = T' = trunc_τ(P_12(X'))，X ≠ X'。∎

**引理 2（状态相同的情况归约为"密钥差状态碰撞"）。** 若 X = X' 而 K ≠ K'，则 Y_R = Y'_R 且 Y_C ⊕ Y'_C = K ⊕ K'。即攻击者找到了两条 keyed-duplex 路径（不同密钥、任意 nonce/AD/消息），其最终化前内部状态满足一个**固定的 512 bit 关系**：速率相等、容量之差恰为 K ⊕ K'。

证明：X = (Y_R, Y_C ⊕ K) = (Y'_R, Y'_C ⊕ K')。∎

（若 K = K' 而 (N, A, M) 不同且 X = X'：这是同一密钥下的内部状态碰撞，也是 512 bit 状态上的碰撞事件，同样落入引理 2 的分析；CMT-4 需要覆盖它。）

**定理（理想置换模型）。** 把 P_12 建模为随机置换 π: {0,1}^512 → {0,1}^512，攻击者可做 q 次 π/π^{-1} 查询。则任意 CMT-4 攻击者成功的概率满足

  Adv^{CMT-4}(q) ≤ q(q−1)/2^{τ+1} + q(q−1)/2^{513} + q/2^{256}。

三项分别对应：(i) 引理 1 的 τ 比特截断输出碰撞（生日界）；(ii) 引理 2 的 512 bit 状态关系碰撞——两条路径的最终状态是 π 的输出（经过至少一次 π 调用），对固定关系 (Y_R = Y'_R, Y_C ⊕ Y'_C = Δ) 的碰撞概率为 q^2/2^{513} 量级；(iii) 攻击者猜中某条路径的 256 bit 容量（从而可任意控制 X）的概率。

证明梗概：任何成功输出都由引理 1 或引理 2 的事件之一见证；两类事件都只涉及攻击者已做过的 π 查询（未查询过的 π 值是均匀随机的，攻击者无法凭空得到相同标签）。对 (i)：q 个不同输入的 τ 比特截断输出两两碰撞概率 ≤ C(q,2)/2^τ（π 是置换，截断后视为近似均匀，偏差 ≤ 1/2^{512−τ}，可忽略）。对 (ii)：任两条路径的最终化前状态由不同的 π 查询链得到，其 512 bit 值满足固定关系的概率 ≤ 1/2^{512}（同样按置换偏差修正）。对 (iii)：容量猜测。∎

**推论。** τ = 256：Adv ≤ q^2/2^{257} + 可忽略项，即需要约 **2^128** 次置换调用——与规范 §0 "128 bit" 一致。τ = 128：Adv ≤ q^2/2^{129}，约 **2^64**——与 §0 "128 bit 标签时降为 64 bit" 一致。τ = 192（若采用）：2^96。

## 4. 为什么设计选择"标签不再与密钥异或"

若定义 T' = trunc_τ(P_12(X)) ⊕ K（Ascon 式），则攻击者的目标变为 F(X) ⊕ F(X') = K ⊕ K'，仍是一个碰撞型问题，代价量级不变。Fable 不采用它的理由是**论证的干净性**而非强度差异：
- T = F(X) 使"标签 = 一个公开函数在承诺全部输入的状态上的截断像"，归约只用到 F 的碰撞难度；
- 密钥已经在 X 的容量部分（Y_C ⊕ K），标签隐式承诺 K；额外异或不增加承诺，反而让"密钥流可从标签恢复"这类分析多出一个分支。

同理，两个参数集（IV1 = 0x012020C8 / 0x012020C6）的域分离不影响承诺：不同参数集的两条路径产生不同的 X（IV1 进入 P_12 的输入），仍归入引理 1。

## 5. 与 CTX 的关系、以及超出理想模型的注意事项

- **CTX**（Chan–Rogaway 2022）通过 T* = H(K, N, A, T) 给任意 AEAD 加承诺，强度为 H 输出长度的一半。Fable 的标签本身已具有"H(状态)"的形状（P_12 的截断像），因此**不需要外挂 CTX**，代价为零。
- 理想置换假设的实际含义：需要 P_12 在**碰撞搜索**意义下没有捷径，即不存在概率显著高于 2^-512 的 12 轮差分（否则可用差分构造 X ≠ X' 且截断像碰撞）。ANALYSIS-LOG 的差分界：2 轮特征 ≤ 2^-31，12 轮的拆分界 ≤ 2^-(31×6) = 2^-186（P_8 的速率受限拆分界见 ANALYSIS-LOG v0.3 阶段 3），远低于生日阈值 2^-128 所需的水平；12 轮 = 24 ChaCha 单轮，超出所有已知 ChaCha 碰撞/差分分析的轮数（≤ 7.5）。
- 承诺是**离线碰撞问题**，与用户数、nonce 重复无关；多用户不会降低它。
- 攻击者若能让两条路径在最终化前**整个状态相同**（引理 2 的 K = K' 情形，即内部碰撞），这对应 keyed duplex 的伪造攻击，其界见 `security-bounds.md`（容量 c = 256 给出 2^-128 量级），与承诺界一致。
- **标签截断的建议**：需要承诺性质的应用应使用 ≥ 192 bit 标签（96 bit 承诺）；128 bit 标签的 64 bit 承诺只适合不以承诺为目标的场景，规范 §0 已如实声明。

## 6. 结论

规范 §3.5 的声明成立：Fable-AEAD 的标签是最终化前完整状态（含密钥、nonce、AD、消息与参数集标识）经 P_12 的 τ 比特截断像，任何 CMT-4/CMT-1 攻击都归约为 (a) 该截断像的碰撞（生日界 2^{τ/2}）或 (b) 512 bit 状态的固定关系碰撞（2^{256}）或 (c) 容量猜测（2^{256}）。在理想置换模型下承诺强度为 **τ/2 bit：256 bit 标签 → 128 bit，128 bit 标签 → 64 bit**，且该界是紧的（通用生日攻击达到它）。
